Overview

Highspeed Hotels and Travel is an application with a main focus on being an interface for booking stays at hotels and houses. Customers can create an account, browse and book a hotel or house, and view their order history. Employees can add, edit, and remove available lodges. Employees can also get all customer order history between selected date ranges.

Highspeed Hotels and Travel is written in Java and uses Microsoft SQL for database interactions. Also utilizes mulitithreading to increase user responsiveness.

Logon

Here useres can sign in, create an account, or sign in as guest.

Customer Page

Here the user can browse and book a hotel or house and view their order history. Clicking on a image opens the large image carousel for easier viewing.

Employee Page

Employees can add, edit, and remove available lodges. Employees can also get all customer order history between selected date ranges.
