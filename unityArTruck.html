AR Truck App

Overview

This is an application for Android devices that displays an interactive AR truck model when the camera is aimed at the target image. The user can play animations for specific parts of the truck, rotate the truck, display additional modeled accessories, and also the ability to change the color of the truck parts with a color slider.

This AR Truck App is written in C#, utilizing Vuforia Engine for AR camera and target image, and made in Unity.

Animations

Here the user can play the open and closing animations either by selecting from the menu or tapping on the animated vehical part. Also here users can rotate the model.

Accessories

Here the user can select an additonal accessory model to display on top of the truck.

Colorization

Here the user can select the color of the body and trim of the truck using color sliders.

Infomation Tab

The final tab displays contact infomation for the company.
